# NTC Micro-Harness Plugin Rules (v2.1)

When working in a repository governed by **NTC Micro-Harness** (or when the user invokes any `/ntc-*` command), always enforce the 6-Step Atomic Engineering Protocol defined in `AGENTS.md` and `docs/WORKFLOW.md`:

1. **Step 1 (`/ntc-init`):** Ask for the **Project Git Repository URL** (optional — can be left blank) + basic requirements **before doing anything else**. Initialize `git init` and connect `git remote add origin <repo-url>` if provided. Ask 3–5 clarifying questions, then generate `PRD.md` and `ARCHITECTURE.md`. Wait for user approval.
2. **Step 2 (`/ntc-prototype`):** If `UI Required: YES`, use `PRD.md` and `ARCHITECTURE.md` to populate `docs/prototypes/registry.md` and build clickable HTML/CSS prototypes (`docs/prototypes/<slug>/scr-<nn>-*.html`) covering `default`, `loading`, `empty`, and `error` states with `data-testid` anchors. Iterate (`--revise`) until locked (`--approve` → `APPROVED`).
3. **Step 3 (`/ntc-spec`):** Synthesize `PRD.md`, `ARCHITECTURE.md`, and approved prototypes into the overall `SPEC.md`, `docs/plans/system-roadmap.md`, and `docs/plans/contract-registry.md`. Once locked by the user, propose and install AI skills per module/service into `.agents/skills/` and generate `ai-skill-maps.md`.
4. **Step 4 (`/ntc-modules`):** Read each module's mapped skills in `ai-skill-maps.md`, combine with `SPEC.md` and approved prototypes, and generate detailed module specs (`docs/modules-spec/<slug>.md`). Once approved by the user, generate the Human-Only Playbook `STEP-by-STEP.md` (Agents must never read `STEP-by-STEP.md` during execution).
5. **Step 5 (`/ntc-plan`):** Pre-generate 100% of Phase Dossiers (`docs/plans/active/<slug>/phase-<NN>-*.md`) with Level-4 Atomic WBS across all modules and verify `python scripts/validate_plans.py --fix` passes with `0 violations`.
6. **Step 6 (`/ntc-run` / `"tiếp tục"`):** Execute strictly **1 Atomic Task per turn (`1 Turn = 1 Task`)**, enforce 1:1 UI Prototype Parity (`SCR-<MOD>-<NN>`), verify with executable proof, update `🎫 Resume Ticket`, run `python scripts/validate_plans.py --fix`, and create an **Atomic Git Commit checkpoint (`HEAD`)**. Support mid-flight Change Requests via `/ntc-cr` (`CR-<NN>` 4-Step Delta Reverse-Unlock) and finish with the Closing `SYS` Full-Stack E2E Gate (`/ntc-status --e2e`).
